# LinkPilot User Guide

1. Open LinkPilot.
2. Complete Setup if it appears.
3. Enter API credentials in Settings.
4. Select or download an Ollama model in Models.
5. Click Start Worker on Dashboard.
6. Use Logs to replay runs and export diagnostics from Release when support asks.

CAPTCHA and OTP screens are reported safely; LinkPilot does not solve CAPTCHA.
